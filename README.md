# Portfólio — Yuri Dorigon

Meu portfólio profissional como desenvolvedor Full-Stack, com os sistemas e sites que construí e mantenho.

**Site:** [yuri-dorigon.vercel.app](https://yuri-dorigon.vercel.app)

## O que tem no site

- **Projetos:** sistemas internos, automações e sites, com capturas de tela reais e sem dados de pacientes.
- **Tecnologias:** as ferramentas que uso, organizadas por área.
- **Sobre:** minha experiência e formação.
- **Contato:** um formulário que abre a conversa no WhatsApp, além de links para LinkedIn, GitHub e e-mail.

## Tecnologias

Next.js 15, React 19, TypeScript, Tailwind CSS e shadcn/ui, com deploy na Vercel.

## Como rodar

```bash
npm install
npm run dev
```

O site abre em `http://localhost:9002`.
